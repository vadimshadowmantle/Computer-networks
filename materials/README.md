# Лекции

| Файл | О чём |
|---|---|
| `Передача данных и сетевые модели.pptx` | Среда передачи и сигналы; виды связи simplex, half-duplex, full-duplex; unicast, broadcast, multicast; типы сетей по протяжённости |
| `Коммутация Ethernet.pptx` | Модуль 7 Cisco: кадр Ethernet, MAC-адреса, работа коммутатора и таблица MAC-адресов |
| `Адресация IPv4.pptx` | Модуль 11 Cisco: структура адреса IPv4, маска и префикс, типы адресов, сегментация и разбиение сети на подсети |
| `Маршрутизация в Cisco.ppt` | Маршрутизация и настройка маршрутизаторов в Cisco Packet Tracer |
| `NAT — теория.pptx` | Терминология NAT; статический и динамический NAT, PAT; плюсы и минусы; настройка и проверка (`show ip nat translations`, `show ip nat statistics`) |
| `NAT в Cisco.pptx` | Пошаговая настройка NAT в Cisco Packet Tracer: VLAN на коммутаторе, sub-интерфейсы маршрутизатора, трансляция адресов |
| `DHCP.pptx` | Предшественники DHCP (RARP, BOOTP), режимы назначения адресов, аренда, обмен сообщениями |
| `DNS.pptx` | Что такое DNS и DNS-сервер, типы записей (A, MX, SOA и др.), корневые серверы, уровни доменов |
| `TCP и UDP — часть 1.pptx` | Транспортный уровень в моделях OSI и TCP/IP, сервисы транспортного уровня |
| `TCP и UDP — часть 2.pptx` | Стек протоколов TCP/IP по уровням и протоколы каждого уровня, TCP и UDP |
| `TCP и UDP — часть 3.ppt` | Продолжение темы транспортного уровня: TCP и UDP |
