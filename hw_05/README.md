# ДЗ 5. IPv4: сеть, узел, маска

**Задание:** установить Cisco Packet Tracer и прислать скриншот работающей программы; распределить сеть 127.168.0.0/24 на подсети для 5 зданий по 15–25 устройств; подобрать маску для 20 подсетей по 10 узлов.

**Решение:** для 25 устройств нужно 5 бит под хосты — маска /27 (255.255.255.224), 8 подсетей по 30 адресов: пять под здания, три в резерве.
