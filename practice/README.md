# Практические работы

Скриншоты практических заданий с пар, выполненных в Cisco Packet Tracer.

| Папка | Что сделано |
|---|---|
| `01. Коммутатор и концентратор` | Сеть из 6 компьютеров: коммутатор и концентратор, прохождение пакетов в режиме симуляции |
| `02. Сеть с серверами` | Компьютер и два сервера через коммутатор, проверка связи `ping` |
| `03. Wi-Fi и этажи` | Беспроводная сеть: компьютеры подключены к домашнему Wi-Fi-роутеру, проверка связи `ping` |
